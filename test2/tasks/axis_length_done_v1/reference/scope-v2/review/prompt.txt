This task uses the unmodified MIT-licensed verilog-axis length-adjustment FIFO controller
at revision 48ff7a7e2ef782cf778d47910cf85835c64b1bce. It is a newly scoped
monitor task on a previously inspected IP family, not an unseen repository or
an official benchmark. The upstream README describes padding/truncation and
original/current length reports; the timing and finite-trace rules below are
the explicit project contract, not a claim of verbatim upstream prose.

The selected wrapper is task_top_v3.sv. Original data/header FIFOs have depths32/8; status can be consumed before the corresponding output frame. The rejected direct-core scope and its status-stability counterexample remain separate qualification evidence. Data width is 8 bits, KEEP is disabled
(each accepted input is exactly one byte), ID/DEST/USER are disabled. Length
limits are constant MIN=4 and MAX=8 bytes. Input frames contain 1..12 bytes.
There is one positive-edge clock and synchronous active-high reset. Reset is
the only cancellation mechanism in this scope; there is no independent cancel pin.

A transfer occurs at a rising edge iff valid and ready are both 1 before that
edge and rst=0. Input s_last marks the final byte of an input frame. The source
holds s_valid, s_data and s_last while blocked, except that reset cancels it.
Input gaps, back-to-back frames and independent data/status backpressure are
legal. Source validity during reset is 0. The sink need not keep ready asserted.

For each accepted input frame X of length L, the expected output frame is:

- L<4: all input bytes, then zero bytes until length 4;
- 4<=L<=8: the input bytes unchanged;
- L>8: the first 8 bytes; the remaining input bytes are still accepted/drained.

Exactly one accepted output beat has m_last=1 per completed output frame, on
its final byte. Frames and bytes retain input order. No output may depend on
an unaccepted input byte. Output may stream before input s_last is accepted;
the checker must support partial known prefixes rather than requiring the
whole input frame to arrive first. Padding is known only after input completion.
For truncation the output end may wait for the rest of the input frame.

Each completed, uncancelled input frame has exactly one status response:
h_original_length=L, h_length=min(max(L,4),8), h_pad=(L<4), h_truncate=(L>8).
Statuses preserve input-frame order. Data and status responses are independent
channels; no required order is imposed between the two channels' completion.
A status cannot describe an input frame before that input frame completes.

If m_valid=1 and m_ready=0, m_valid/data/last remain stable until transfer or
reset. If h_valid=1 and h_ready=0, h_valid and all status fields remain stable
until transfer or reset. Payload fields when their valid is 0 are unspecified.
s_ready is flow control, not an independently prescribed cycle-by-cycle value.

Reset cancels in-progress input and all not-yet-consumed data/status responses.
After the reset edge m_valid=h_valid=0. Already consumed output prefixes are
not retroactively failures: reset discards the remaining epoch. No pre-reset
obligation may be carried into the next epoch. A reset edge performs no transfer.
Pre-edge observations while rst=1 may still show pre-reset values.

This is a two-state task. Saved -1 observations denote X/Z and are unresolved
when meaningful, never successful checks. The initial pre sample is excluded.
At every subsequent pre/post sample, valid fields and enabled payloads are checked.
Unknowns must not erase an earlier definite violation.

Finite evaluation traces declare require_drained=true and end in an uninterrupted
ready-high, reset-low, no-new-offer tail of at least 32 cycles (development) or
128 cycles (final). For the fixed bounded offered workload, all offered bytes
must be accepted and all uncancelled responses consumed by the end. Remaining
s_valid/m_valid/h_valid, an incomplete accepted input frame or remaining expected
responses is a finite completion failure, not permission to infer an unbounded
liveness guarantee. Partial unit controls may use require_drained=false.

## Sampling clarification v2

This registered FIFO task has no zero-latency pre-edge bypass. At pre(n), valid payload/status must be justified by inputs accepted at earlier edges; a current input offer does not justify a pre-edge output. At post(n), the input accepted at edge n is included. A presented m_valid or h_valid without the requisite already accepted input/frame is a specification failure even if ready=0 and even if a later reset cancels it.     if not isinstance(rows, list) or len(rows) == 0:

            return 'row %d: cycles must be consecutive from 0' % i
        for k, spec in (('inputs', _INW), ('pre', _OUTW), ('post', _OUTW)):
            d = r[k]
            if not isinstance(d, dict) or set(d.keys()) != set(spec.keys()):
                return 'row %d: %s must contain exactly the documented fields' % (i, k)
            for f in spec:

def _exp_beat(frames, fo, pos):
    # (kind, expected byte or None, expected last) from accepted input only
    if fo >= len(frames):
        return ('noframe', None, None)
    fr = frames[fo]
    b = fr['b']
    n = len(b)

        return ('ok', b[pos], pos == MAX_LEN - 1)

    return ('premature', None, None)

def token_cost(records):
    attempted=[r for r in records if r.get('generation_request_issued')]
    known=[r.get('usage') for r in attempted if r.get('usage') and isinstance(r['usage'].get('input_tokens'),int) and isinstance(r['usage'].get('output_tokens'),int)]
    # Missing usage is unknown, never a zero-cost failed request.
    return dict(generation_requests=len(attempted),count_requests=sum(bool(r.get('count_request_issued')) for r in records),
                known_input_tokens=sum(u['input_tokens'] for u in known),known_output_tokens=sum(u['output_tokens'] for u in known),
                unknown_usage_requests=len(attempted)-len(known),
                actual_total_tokens=sum(u['input_tokens']+u['output_tokens'] for u in known) if attempted and len(known)==len(attempted) else None)

def decode(path,slot):
    scopes=[];ids={};outputs={};checks={};step_id=None;header=True;values={};touched=set();frames={};partial={}
    def flush():
        if step_id in values:
            step=values[step_id]
            if step<0:raise ValueError('Unknown SMT step')
            if set(ids.values())<=touched:frames[step]=dict(values)
            else:partial[step]=set(ids.values())&touched
    for raw in Path(path).read_text().splitlines():
        line=raw.strip();w=line.split()
        if header:
            if line.startswith('$scope '):scopes.append(w[2])
            elif line.startswith('$upscope'):scopes.pop()
            elif line.startswith('$var '):
                if w[4]=='smt_step' and not scopes:step_id=w[3]
                if scopes==['formal_top'] and w[4] in ('active','ok'):
                    if int(w[2])<=slot:raise ValueError('Selected monitor bit absent from VCD')
                    checks[w[4]]=w[3]
                if scopes==['formal_top'] and w[4] in set(ROW_INPUTS)|set(OUTPUTS):
                    if int(w[2])!=PINS[w[4]]:raise ValueError('Formal public pin width changed')
                    target=ids if w[4] in ROW_INPUTS else outputs
                    if w[4] in target:raise ValueError('Duplicate public pin')
                    target[w[4]]=w[3]
            elif line.startswith('$enddefinitions'):header=False
        elif line.startswith('#'):flush()
        elif line.startswith('b'):
            bits,ident=line[1:].split();value=-1 if any(c in bits.lower() for c in 'xz') else int(bits,2)
            if ident==step_id and values.get(step_id)!=value:touched.clear()
            values[ident]=value;touched.add(ident)
        elif line and line[0] in '01xz':
            ident=line[1:];values[ident]=-1 if line[0] in 'xz' else int(line[0]);touched.add(ident)
    flush()
    if set(ids)!=set(ROW_INPUTS) or step_id is None:raise ValueError('Missing formal input pins')
    if len(frames)<2 or sorted(frames)!=list(range(len(frames))):raise ValueError('Incomplete reachable witness')
    if any(s not in frames and (s!=len(frames) or fields) for s,fields in partial.items()):raise ValueError('Truncated input frame')
    inputs=[{k:frames[i][v] for k,v in ids.items()} for i in range(len(frames))]
    if any(v<0 or v>=2**PINS[k] for x in inputs for k,v in x.items()):raise ValueError('Unknown/out-of-range input')
    sampled=[{k:frames[i].get(v,-1) for k,v in outputs.items()} for i in range(len(frames))]
    if set(checks)!=set(('active','ok')):raise ValueError('Selected formal monitor observations absent')
    bad=[i for i in range(1,len(frames)) if all(frames[i].get(v,-1)>=0 for v in checks.values()) and
         (frames[i][checks['active']]>>slot)&1 and not (frames[i][checks['ok']]>>slot)&1]
    if not bad:raise ValueError('No definite selected-slot alarm state in VCD')
    return inputs,sampled,bad[0]

def legal_inputs(inputs,rows):

    count=0
    for i,x in enumerate(inputs):

            if x['s_valid']:raise ValueError('Source offered during reset')
            count=0;continue
        if i and not inputs[i-1]['rst'] and inputs[i-1]['s_valid'] and rows[i-1]['pre']['s_ready']==0:
            if any(x[k]!=inputs[i-1][k] for k in ('s_valid','s_data','s_last')):raise ValueError('Blocked source offer changed')
        if x['s_valid'] and rows[i]['pre']['s_ready']==1:
            count+=1
            if count>12 or count==12 and not x['s_last']:raise ValueError('Frame length assumption violated')
            if x['s_last']:count=0
