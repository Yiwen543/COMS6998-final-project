# 事务监视器的分支等价证明协议

本协议在运行新比较前冻结。研究问题是在同一组规则、同一对原始表达式下，按源代码中已经存在的数值边界分情况，能否得到全局 e-graph 未找到的完整等价证明。研究对象是监视器的语义与证明覆盖率。沿用原始事务实验的已归档输入，本轮没有新的模型调用或 RTL 修改。

## 负载与对照

- **真实模型候选。** 纳入最近一次真实事务实验三个无辅助初稿。对每个性质将三份初稿两两比较，排除文本相同的端点，再按性质名及无序的两个原始候选文本去重。18 次非相同比较形成 12 对，保留相应 trial 编号；左右两端均来自真实模型。分类标签由独立全位宽 oracle 重新判定。
- **已知错误候选。** 纳入同一事务实验冻结的九条 fixture 初稿，各自与对应原始参考比较。完整保留每个性质和原始错误，逐项检查零误证；保存能具体回放的 SAT 反例。与真实候选分组报告。
- **边界控制。** 另设固定的小型合成等价对及只改变一个边界的近似错误对。固定输入清单在运行前登记，同一清单供所有方法使用。合成负载只测机制，单独报告；重复条件、恒等端点和同组重复文本明示。
- **独立基准。** 对每一对在全体良类型、二态的完整位宽赋值上求解原始两端的 XOR，记录 SAT/UNSAT/UNKNOWN 和 SAT 具体模型。此处所有引脚与历史字段自由，不采用先前事务快照评级中的 ghost 结构约束。这份查询用于判定证据质量，禁止将一整对的等价结论当作 egg 规则。
- **全局 egg。** 一个无条件分支。原始共同抽象映射中的每一个原子仍是独立叶子，条件预处理只可加入经此分支 SMT 查询认证的叶子事实。通用规则为固定的 19 条布尔化简规则，另加 AND、OR 的结合律与交换律四条。两端原始抽象项都交给同一 Rust 二进制。
- **分支 egg。** 阈值仅取自待比较表达式自身，按固定、确定的策略建分支。各次运行的原始抽象端点、23 条通用规则、单图资源上限与全局组一致。每个可行分支使用独立 e-graph，只加载其自身已获 UNSAT 认证的叶子事实。不得将分支 A 中的真值、别名或 e-class 传给分支 B。记录总图数和总预算，分支求和的计算成本可高于单图。
- **普通推理对照。** 在同一组原子、同一分支和完全相同的已认证叶子事实下，用普通命题求解器检查原始抽象端点的 XOR，记录判定。该对照识别条件分解和 SMT 预处理本身的贡献，也可直接判断 egg 相对强普通方法是否提供了额外证明覆盖。

冻结的八条控制如下。表中比较操作使用对应引脚位宽的无符号语义。

| ID | 比较构造 | 预设标签 |
|---|---|---|
| C01 | 固定 `data_n = 4` 时比较 `data_index = data_n` 与 `data_index = 4`，两边均与同一 guard 合取。 | 等价 |
| C02 | C01 两边的 guard 同时改为 `data_n ≤ 4`。 | 不等价 |
| C03 | 当 `header_n < 8` 时要求 `h_length = header_n`，否则要求 `h_length = 8`；另一边把分界改为 `header_n ≤ 8` 和 `header_n > 8`。 | 等价 |
| C04 | C03 的另一边保留 `header_n < 8`，仅将第二段改为 `header_n > 8`，从而漏掉边界。 | 不等价 |
| C05 | guard 为 `m_data = 0`，比较 `data_byte = m_data` 与 `data_byte = 0`。 | 等价 |
| C06 | C05 的 guard 与右侧常量均改为 255。 | 等价 |
| C07 | C06 保留 guard，只将右侧比较改为 `data_byte = 254`。 | 不等价 |
| C08 | 取真实 trial 1 的 `data_last`，复制后把唯一的 `data_n ≥ 4` 改为 `data_n > 4`。 | 不等价 |

## 可接受的证明

1. 存档从原始有类型文本得到的共同抽象端点及原子映射。先证明分支合起来覆盖声明的输入域，每两个不同分支互斥，并单独检查每个分支是否可行。只有经 UNSAT 判为不可行的分支可以跳过；覆盖、互斥或可行性未确定时，不能发放完整证书。认证所用的位宽、符号定义和前提必须列明。除非明确限定，叶子事实不依赖 DUT 输出正确或真实 RTL 可达。
2. 事实仅允许原子与布尔常量、其他源原子或其否定之间的关系。每条本地事实以分支 guard 为前提，重新从原始有类型叶子生成违例 SMT 查询。必须得到 UNSAT；只接受与该 guard、叶子端点和位宽绑定的那份查询。图中的抽象端点保持原样，不在提交前用局部事实改写。命题对照及 egg 使用的事实清单完全相同。
3. 通用规则按完整布尔真值表预核验，包括正向会丢弃的变量。对每个非恒等的合并，逐行检查具名改写的方向、树路径、改写前后的完整子树及共享匹配变量，并检查最后一行确实到达另一原始端点。逆用变量消去规则时，额外变量必须由实际新子树给出。恒等端点、完整具名证明、饱和未合并、资源上限分别记录。硬资源上限与合并同时出现时，允许认可已完整、独立重放的局部证明，并保留当时的停止原因；未给出证据的合并不计作证明。
4. 仅当分区有效、所有局部依赖已验证、**每个可行分支**均获得独立认可的局部证明，才能获得整对的条件分类等价证明。对 SAT 的原始表达式对发放证明、使用其他分支的事实、漏掉分支、拼入另一条“刚好也是 UNSAT”的查询或伪造改写，都应被审计拒绝。出现误证须保留并调查，不能从分母里剔除。

## 指标和边界

分别列出每类工作负载的总数、完整证明、结构恒等、未证、全位宽 oracle 分布和错误发证数；列出同一对仅某一种方法成功的情况。逐对保存阈值、可行分支数、局部 SMT 查询数与耗时、认证与实际使用的叶子事实、各分支改写步数、停止原因和原始证明。普通对照与 egg 端到端的耗时包含预处理，并区分 SMT、本地图搜索和独立复核。小样本计时仅说明复现实验的资源开销。本轮不会据此推断 RTL 验证加速、模型 token 减少、故障检测率提高或真实硬件上的可达性。
