# Source and P2 progress publication

This revision publishes project source, public task scaffolding, selected result
summaries, and the B5 P2 manuscript and editable sources. It is **not** a complete
mirror of the locally retained historical run and audit archive.

The full historical raw results, model request/response records, intermediate
builds, and audit snapshots remain preserved locally. They were not included in
this limited publication. Existing freeze and result documents describe their
original recorded scope; their presence does not imply that every referenced raw
artifact has been distributed in this revision. No missing artifact was replaced,
recomputed, or relabeled to produce this publication.

The current manuscript is available from [Milestone 2](MILESTONE2.md). Its pilot
figure uses saved controller results: final detection ties at 11/11 confirmed
observable types, with the raw 12-type denominator retained; C uses 9.8571% more
generation tokens. These are finite, scoped results, not general correctness or
isolated semantic-causation claims. Authentic instructor/TA technical feedback
and its response are still pending. No course submission was performed.

The [I2C READB task card](../test2/tasks/i2c_read_p2_draft_v1/task-card.md) is offline
preparation. The new adapter, hidden inputs, and physical mutants are not an
implemented or tested live study. G1 preparation and its retained failure do not
constitute completed general tool qualification. No online model test was
started for this publication.

Local document compilation and plotting caches are excluded from Git. The P2
PDF, editable LaTeX, source ZIP, figure, and numeric plot data are included.
