# AXI Frame Length Adjuster · 规格验证与 LLM 反馈实验设计

上次真实 API 实验中，三组第一轮都把预定义的五个布尔量组成正确监视器。本轮使用原项目 `frame_task` 公共 wrapper、数据 FIFO 深度 32、头部 FIFO 深度 8、8 位数据和固定最小/最大帧长 4/8。目标是直接验证真实 RTL 的数据和头部规范，并研究 egg 能否对较复杂的类型化断言提供可复核的推导。固定输入来源为原参考仓库 `e94172a1bd5e9b138b5fc3da01554edb3052ce52`。

## 两种独立验证

- 按真实输入握手构建长度、数据和头部队列参考结果。使用原项目固定的独立参考检查器，在 Icarus 上回放所有 1–12 字节长度组、数据/status 独立及同步阻塞、连续帧和复位相关轨迹，检查 drain 后的完整事务结果。复位时撤销未完成事务的语义沿用公共规格。保留失败及未知结果。
- Yosys/Z3 对原 wrapper 检查跨沿的两路 backpressure 保持，以及任意有效头部的 pad/truncate 位和夹紧长度一致性。每条性质独立运行 BMC 或归纳；同时搜索触发场景，避免空洞通过。记录实际深度。使用原始协议的合法输入与最大帧长条件，原始 report length 与已接受原帧长度的对应关系由独立事务检查器覆盖。两种验证的结论范围分别报告。

## 类型化候选断言与反馈

五个局部监视目标：`data_hold`、`header_hold`、`pad_flag`、`truncate_flag`、`clamped_length`。候选使用公开接口信号和显式前一拍（采样在相邻上升沿之前）、8/16 位无符号比较和布尔运算。原始 DUT 不变。固定的手写参考违例式仅在评分器和证明查询中使用。每个候选由完整类型化公式的独立 Z3 XOR 查询核对；若有不等价反例，说明存在不同采样赋值，具体可达性由 RTL 记录或形式模型另行决定。设计之间的事务级正确性使用同一个独立检查器。

为观察反馈作用，三组从同一批固定错误断言出发；数据阻塞误用本拍 ready、头部保持漏掉 original length、pad/truncate 在恰好 4/8 处使用不严格不等式、夹紧长度只比较输入与输出长度。该初始批是预设的错误监视器。复核它确实包含五种不同的错误。第一轮前各组收到其各自反馈策略的结果，然后在固定轮数内修订五个候选。raw 只看到实际观察的候选报警计数、首拍及有限事务 checker 结果；ordinary 和 egg 收到同样的可见 RTL 结果和独立等价 oracle 的反例，再附上各自实际完成的证明摘要。两组共享带类型原子等价关系和作用域；ordinary 使用普通归一化及强抽象命题 SAT 判定，egg 使用固定六条通用布尔规则加已认证原子改写。两种搜索能力有区别，明确记录资源上限和未证明结果。三组的候选分别进行统一评分，分别记录全部五个公式的等价性和真实轨迹命中/误报/漏报/未知。

在运行任何故障对照前固定开发可见性：原版、F02、F05；两个故障以中性 Probe A/B 标识。F01、F03、F04、F06 的结果从模型反馈中保留。原版和每个故障均用同一套公开长度扫描、阻塞及复位测试场景。局部监视器与完整事务 scoreboard 的检测范围不同，评价时先列出哪些故障实际触发了参考监视器，再报告候选链路在相同证据上的结果，禁止将其他故障记为局部监视器漏检。

## 指标与执行

主要指标为满足原规格的候选数、规定预算内首次五项通过的轮次、在真实 RTL 轨迹中对参考断言的漏检/误报，以及普通改写和 egg 各自独立证明的数量与步骤。事务级原始数据、头部和帧长评分由独立检查器报告。模型调用统一使用指定模型、推理等级、输出上限及各自的历史，记录真实 token。离线预置回复用于检查驱动和证明链路；下一批真实对照需单独执行。不得从预置回复推断模型行为改进。完整设计不依赖当前 DUT 已知正确，也不根据 egg 的输出选择更有利的故障样本。
