# Frame · 证明覆盖与报警分解实验协议

本轮研究的目标是让 egg **参与验证中的解释与断言生成**，不是比较整体 RTL 验证加速。上一轮实际 API 实验留有两个等价监视器未被旧规则引擎证明，且五条监视器只覆盖部分实际故障。本协议在新结果生成前固定主要比较方式。

## 预注册的诊断实验

- 输入只用 `egg_frame_terms.REFERENCES` 中原有五条 RTL 规格的违规谓词。其类型、引脚位宽、当前/上一时钟 PRE 采样均沿用此前的实验。诊断提取只接收一个 Boolean 抽象源，不提供任何目标分解、实际故障结果或候选 DNF。
- 冻结的生成规则：旧六条布尔规则，右向 and/or 结合律、左右分配律、and/or 幂等律，见 `scripts/egg_frame_diagnostic.py`。不加入交换律或反向分配律以控制搜索空间。每条规则独立穷举自身变量真值表；egg 0.11 用 20 轮、20,000 节点、5 秒的搜索预算。
- 在实际 e-class 中寻找析取范式（OR of ANDs of signed atoms），按子句数、文字出现次数、AST 节点数依次最小化；这只是给定搜索图内的提取目标，不是全 Boolean 公式最优性的证明。失败或不饱和时不计生成成功。必须逐步审核非恒等的 egg 具名解释，将抽象原子严格还原为完整位宽谓词，独立 Z3 验证整个所生成的表达式与源谓词等价，并对每条子句检查 `clause ∧ ¬source` 不可满足。不能将无证明或超时算成成功。
- 强普通基线：确定性的 NNF→DNF 展开、消除重复和矛盾文字、子句吸收；同样以位宽 Z3 验证，不因 egg 子句数较小就单独认定有效。再以独立穷举 Boolean 原子空间的最小充分文字集合为每个确知报警的强基线（最多 12 个原子；不使用不可见值，不把抽象原子之间可能的位宽依赖用于缩短基线）。
- 实际轨迹主语料为先前固定 21 条轨迹（原版、F01–F06，每版三个场景），另外加入另行固定的输出端敏感性控制 D01–D03，后者独立报告，不合并到之前的真实故障检出率。每个样本先以原有独立完整位宽采样判定，再用生成出的整体谓词重新判定，包括 X/Z 的二态完成；对确知报警，比较 egg、普通 DNF 的最短已知为真的子句，以及独立穷举的最短已知充分文字集合。
- 报告每条性质、每种故障和合计的报警次数、全部样本的匹配/不匹配/未知、可解释报警数、子句数和解释文字数、例子及停止原因。不把子句描述误称为根因；它只是足以触发局部谓词的条件。原始 RTL 的事务检查与此前形式验证结论不变；不宣称这五条监视器覆盖完整帧规格。
- 本轮不发送模型 API 调用，不改变历史在线反馈，不将静态证明质量作在线 LLM 效果的替代测量。新的诊断解释是否改善在线 LLM 需要另设真实在线比较。

## 证明覆盖实验

证明覆盖与单源生成是不同实验。比较同一原子抽象与认证替换下的通用 egg 规则配置；使用已归档实际候选及 seed 负例、冻结的合成等价结构变体与预设回复，分别统计，包含强普通基线和独立位宽等价性判定，不用候选数量重复计算同一公式。见 `scripts/egg_frame_proof_coverage.py` 中的固定变体及具体规则。旧 indexed 在线配置的历史 3/5 单独保留，不混入新通用引擎的对比。对非饱和图，分别统计可独立核验的目标证书与符合旧严格饱和门槛的证书；未找到证明始终不是不等价的证明。

## 观察规则膨胀后的追加控制（独立于上述主实验）

宽规则配置的初次结果在全部 34 对上到达资源上限，虽有可独立复核的等价证书，但旧的“必须饱和”接口不予通过。追加一次固定对照：相同 34 对、同一个宽规则配置和相同预算，只改变是否在待证明的两个同域表达式合并时结束搜索。分别记录真实停止原因、已核验等价证书与严格饱和指标。提前结束证明的是这对目标的等价性，并不意味着搜索图饱和、全局最优提取或未合并的两个式子不等价。历史和默认接口的停止语义保持不变。
