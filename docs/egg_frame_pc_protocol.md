# Proof-Carrying LLM Verification · 固定实验协议

目标：在真实 AXI Frame Length Adjuster 的断言修订闭环中，让 egg 生成的、独立可核验的候选诊断证书真正进入 LLM 的下一轮输入；测量它是否比同样的反例和强普通诊断额外有用。冻结比较方案不以结果为依据。既有 RTL、五条规格、原有形式环境和事务 checker 均不变。

## 实验组与同条件比较

- `raw`：同样的自然语言规格、完整位宽语义判定、开发集的 RTL 观察、每个不等价性质一个确定的反例。
- `ordinary`：raw 全部信息，再加入从当前候选自身推导的最短充分已知文字集合。
- `egg`：ordinary 全部信息；仅增加经独立核验的、与同一充分条件关联的 egg 等价改写证书。生成失败、缺少相同子句、达到资源或反馈大小限制时明确不可用。不把不同反例、不同诊断文字数或更多开发波形作为 egg 优势。

用三组共同的实际候选和原始参考规格跑完整位宽 XOR；跨组匹配候选使用同一份回执和反例。对每条性质先在原版、F02、F05 的固定开发轨迹上找第一个可确定的参考/候选不一致 PRE 样本；若找不到，用 Z3 全位宽反例，从而区分是否真实可达的观测。模型不获得留出 F01/F03/F04/F06 的名称、波形及判定。所有臂保留独立历史、相同模型和输出上限、固定轮数（不因某组先成功改变调用预算）。按 profile、trial、round 轮换三组调用顺序。

## 证明和答案隔离

诊断生成器只接收 **模型当前提交的候选** 、观测到的值及其真假。如果候选报警为真，解释候选为什么报警；如果候选漏报，解释 `not(candidate)` 为什么为真。在最多 12 个独立布尔原子上穷举，求已知文字组成的最短充分条件，独立 typed Z3 检查其蕴含。未知引脚通过可能补全处理，不能随意选定一个值。模型只能看已知充分条件，不能看完整参考公式或参考公式分解。证书输入同样只来源于候选的正/负极性表达式。

用上一轮真实 source-only egg 的固定规则及 20 轮/20,000 节点/5 秒预算生成析取范式。独立验证具名改写的各步及完整位宽等价、各子句充分性；仅当同一个普通最短充分集合确实是 egg 产生的一个经过核验的子句，且完整证书符合固定 32 步/6,000 字符反馈预算，才提供证书。证明只证实**当前候选与其分解等价**，不是候选满足参考规格的证明。对根因定位、未知值、不可达性、失败改写都不作多余推断。保留原始证据于评估档案，不发给模型。

## 工作负载和评估

三种冻结起点：之前实际在线实验预设 seed（historical）、每条含多处自然错误的 mixed、在边界/时间条件上较难暴露的 corner。每个起点五项均需被独立 oracle 证明不等价。固定离线两轮预设回复：第一轮只修复两条，第二轮修复五条；仅用于验证真正的反馈传递、计数、隔离、完整记录、无证书情况和完整评分，不模拟 LLM 对反馈的反应，不测模型 token。真实模式每个起点/重复/组独立会话，使用相同显式模型、reasoning effort、固定最大输出和轮数；支持选择较小子集预算。报告每轮五项语义合格数、额外/漏报、未知采样、首轮合格及首次合格轮次、实际 provider input/output/total usage、证书传递覆盖、反馈字节数（非 token）。全量旧的 21 条真实 Icarus 轨迹仅用于评分，开发反馈只含上述子集；模型并不直接运行重仿真。原有事务 checker 仍独立，5 项监视器不能代表完整规格。

若实测模型返回多轮合法等价断言，可额外对唯一合格表达式生成新 SV，运行原版固定形式环境；不得将抽象等价检查误称为 RTL 可达性验证。本轮若没有实际 API key，只报告离线闭环及入口，保留真实实验为待跑，不使用预设回复替代真实模型推断。

## 第一次离线运行后的追加（不改变上述 DNF 实验）

首次 DNF fixture 观察到 24 个共同诊断机会中只有 10 个得到可发送的完整证书，14 个因整个否定式展开达到 egg 搜索限制；corner 的 8 个机会均受限。因此事后另设一项同输入的证书目标对照：将共同最短充分条件指定的每个抽象原子替换为对应 `true/false`，其余原子仍自由，要求 egg 将剩余表达式证明为 `true`，而不是生成完整 DNF。使用固定、穷举认证的布尔常量折叠、互补、幂等、双重否定与德摩根规则（不使用分配展开），目标合并后停止。每个改写具名证明及替换绑定独立重放，完整位宽蕴含独立验证，原反馈预算保持 32 步和 6,000 字符。与 DNF-run 使用同样的预设起点、修订、开发样本和公共诊断；所有臂使用相同的、适用于两种证书的任务说明，重新运行固定 DNF 对照。新策略证实的是充分条件，而非整个 DNF 的等价性，故不将两种证书当作等强的结论。此追加通过 `--certificate-mode cube` 选择，归档另外保存。真实模型反馈效果仍须新的在线实验。
