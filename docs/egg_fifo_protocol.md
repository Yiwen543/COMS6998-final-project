# 下一轮实验方案 · 用 egg 检查 RTL 规格的拆分

在公共 AXI-stream FIFO 的固定参数实例上，直接验证一条跨拍规格。上拍在非复位状态下 `TVALID=1`、`TREADY=0`，本拍仍非复位，则本拍必须继续保持 `TVALID`，且 `TDATA`、`TLAST`、`TUSER` 均与上拍相同。

将该性质表达为一个失败条件，再生成分别定位四类违例的检查。研究问题是 egg 能否给出可独立重放的等价证明，证明拆分保持原规格，以及不等价的改写是否会被错误接受。将组合层内已经采样的时序项视为独立布尔量。使用 Z3 检查实际 DUT 的跨拍性质和触发场景，两个检查层使用相同的拆分表达式。布尔赋值反例可以证明两个公式不同，具体赋值能否在 DUT 上到达由时序模型决定。

- 固定候选包含自动生成的逐项和分组拆分、等价的蕴含写法，以及漏掉边带检查、错用本拍 `ready`、漏掉复位条件等误写。每个候选以独立进程运行 egg，仅输入这一对公式。输入规则为通用布尔等式，由真值表逐条验算，记录具名证明和独立逐步复核结果。引擎未能证明时保留该状态。
- 普通对照包括结构归一化和显式树上的有界双向搜索。后者使用同一批等式，试验预设 64 和 1,024 个不同表达式的预算，单表达式上限 96 个节点。egg 使用固定的饱和上限，两个搜索空间的节点数不可直接换算。独立真值表为每对公式提供等价判定，列出不同赋值数和一组反例（若有）。
- 原始 FIFO、原始性质、拆分性质和明确注入的违例均保存其标识。同一设计上，两种写法的安全检查应得出同一结论。原版必须能覆盖阻塞场景。对注入故障，用对应的逐项断言列出错误字段，并用没有形式监控逻辑的 DUT 回放求解器给出的输入。记录有界深度和归纳结果。
- 主要指标为公式与证明的正确性、可重放性和诊断粒度。耗时留作辅助信息。此实验不衡量 egg 对任意 RTL 的证明能力，也不从一次实验推断普遍性能或人工节省。
