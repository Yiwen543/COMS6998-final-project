# Follow-up ablation: dependency-first typed triage after a failed prerequisite

This is a separately frozen **post-primary** ablation, not a change to the earlier dependency protocol, workload, or outcomes. The first experiment observed that broad fact discovery and native search were still performed after actual prerequisite SAT, even when a historical equality goal was no longer true. In the real 4→5→4 history, both stale carries incurred unnecessary full search. On the controlled ladder one blocked path instead has an equivalent goal, so inferring inequality from a failed dependency would be unsound.

Comparators: repeat `egg_dependency` and `ordinary_dependency` unchanged, and run one new variant of each applying the following additional policy. In a group, after the initial targeted lookup says **no reusable path**, iff at least one attempted prerequisite is certified SAT under the current guard, execute the exact full-width incremental two-direction target comparison before full discovery. If it reports a definitive non-equivalence (strengthened, weakened, incomparable), accept only that typed selective classification, do not send that pair into broader fact discovery/abstract/native proof search. If all pending pairs were discharged, skip the group's full inventory entirely. If the complete target is equivalent, continue unchanged full discovery and proof generation to retain a new certificate; if the full target is unknown, retain fallback/unknown handling. There is no skip based on missing/unknown leaf or topological miss alone. Count the additional exact target checks, use their existing definitive result if a later proof search misses, and retain all evidence. Do not use the external grading oracle to choose the strategy. No other budget, workload, grouping, or comparison rule changes.

Use precisely the seven primary workloads (the 224-request matrix, six real archived live assessments, ten ladder controls, and four six-request portfolio scaling controls), with fresh isolated caches/stores. Reproduce the earlier two dependency arms' counters, independently grade every verdict, replay all accepted proofs, and explicitly check every triage event against the exact target and the prerequisite receipt. Report proof coverage, search reductions, true-target reproof despite blocked path, and total full-width checks including both dependency and triage. Distinguish a reduction relative to eager/dependency-first traversals from a gain over strong direct SMT. No new model calls or real design changes.
