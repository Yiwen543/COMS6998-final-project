# Scoped I2C write-mode wire checker\n\nScope: OpenTitan i2c_controller_fsm (FifoDepth=64) in write mode with the supplied passive target environment. The checker is spec-derived from the excerpts only.\n\nChecked: MSB-first 8-bit wire bytes and ACK slot, decoded from physical SCL/SDA edges in chronological order (prev post, pre, post). An SCL rise becomes a committed data bit only after SCL falls without an intervening START/STOP. The ninth rise finalizes byte+ACK. Bytes are scoreboarded against the push order minus flushes. Also checked: START/STOP flags, FMT head consistency, pop only after the wire byte, bus composition against launch pins and external pulls, reset non-driving, NACK halt (anchored at the ACK falling edge), and timeout STOP with release.\n\nEvents require a failure-free window from origin to final STOP, a complete correct byte, and public status witnesses.\n\nNo exact core-cycle liveness is imposed. Open transactions, partial bytes, pending FIFO entries and unfinished recoveries are reported as `unresolved` (verdict pending) and are never credited.\n\nExcluded: read mode, RCONT, arbitration and multi-controller operation, analog/timing parameter compliance, bus monitor/bus_free, full register interface, timeout latency bounds, and SDA stability checks. This is not a full I2C or IP correctness claim.
