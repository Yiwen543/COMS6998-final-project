# Disclosed FIFO equivalence stress variant

The original public-domain ZipCPU `sfifo.v` remains unchanged at
`../heldout_sfifo/rtl/sfifo.v`. The variant in `rtl/sfifo.v` is generated by
`scripts/build_sfifo_stress_variant.py`. It deliberately adds source-distinct,
functionally redundant branches near full occupancy and pointer wrap. Those
branches are a **synthetic mechanism stress test**, not naturally occurring
properties of a second benchmark IP. The functional specification sent to
all experimental arms is in `docs/specification.md` and contains no guidance
about these branches or E-graphs.

At `BW=8`, `LGFLEN=4`, asynchronous front read and no access on full/empty,
Yosys `equiv_make`/`equiv_simple` proved all 157 paired cells. `equiv_induct`
had zero unproven cells left to handle. This establishes fixed-configuration
two-state cycle correspondence under matched state/register names and init;
it is not a four-state proof, a proof for all parameter values, or a complete
proof that the FIFO conforms to its specification. The separate public-I/O
checker is retained. The original coverage denominator is never merged by
egg grouping.
